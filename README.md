# Vanguard Open 2026 submission package

- Official deadline: 2026-09-25 23:59 Pacific Time.
- Prize pool: USD 1,000 ($500 / $300 / $200).
- Format selected: written work, maximum 2,500 words.
- `entry.md` includes the work, required sub-300-word rationale, AI disclosure,
  and placeholders for legally personal entrant information.

The remaining boundary is registration, personal review/authorship confirmation,
entrant information, and submission of the final PDF. AI use is explicitly allowed
but must be disclosed; the included disclosure must not be removed.

Run `python3 validate_package.py` before upload to recheck the 2,500-word entry
limit, 300-word rationale limit, AI disclosure, PDF presence, and personal-field
boundary.
